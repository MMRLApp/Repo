# Misnomer

**Gaslight Android.**

Misnomer is a lightweight root module for changing the Android device identity properties reported by your device.

Features include:

- Modern WebUI
- View current identity values
- Change Model, Brand, Manufacturer, Device, Name and Product
- Systemless property modification using resetprop
- Persistent configuration
- Restore original values
- Automatic update support

Misnomer is designed primarily for KernelSU and KernelSU Next.

Magisk compatibility is currently experimental through KsuWebUI.

Source code, documentation and releases are available on GitHub.
