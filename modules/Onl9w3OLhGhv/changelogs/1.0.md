# Misnomer v1.0

The first public release of **Misnomer**.

**Gaslight Android.**

### Features
- Change Android device identity properties through a WebUI
- Model
- Brand
- Manufacturer
- Device
- Name
- Product
- Persistent property configuration
- Restore original values
- KernelSU WebUI support

### Installation
Download `Misnomer-v1.0.zip`, install it through your root manager, and reboot.
