# Misnomer v1.0.2

A visual and presentation update for **Misnomer**.

### Changes
- Added the new Misnomer banner
- Added **"Gaslight Android."** branding
- Added the banner to the WebUI with a background fade
- Improved overall WebUI presentation
- Added project documentation and GitHub release support

### Compatibility
- KernelSU
- KernelSU Next
- Magisk support is currently experimental and requires KsuWebUI for access to the WebUI

### Installation
Download `Misnomer-v1.0.2.zip`, install it through your root manager, and reboot.
