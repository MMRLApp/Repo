# Misnomer v1.0.3

This update focuses on improving the overall user experience and preparing Misnomer for future releases.

## What's New

### Automatic update support

Misnomer now supports automatic update checking through compatible root managers.

Future releases can now be discovered and installed without manually checking the GitHub repository.

### Installer improvements

The installer has received a visual refresh with:

- Improved installation messages
- Clearer installation progress
- Better feedback during installation
- A small amount of additional personality

### Project improvements

- Added update metadata
- Added changelog support
- Improved release workflow
- General repository cleanup

## Upgrade

Existing users can simply update through their compatible root manager once the update becomes available.

Fresh installations can download the latest ZIP from the Releases page.
